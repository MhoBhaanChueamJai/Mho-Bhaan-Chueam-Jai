# หมอบ้านเชื่อมใจ — หมอพื้นบ้านยุคใหม่ ด้วย AI

แอปมือถือ (React Native + Expo SDK 54) สำหรับหมอพื้นบ้านไทยอายุ 40–80 ปี
โจทย์: **เร่งบันทึกองค์ความรู้ฝังลึก (Tacit Knowledge) ของหมอพื้นบ้านก่อนสูญหาย** และยกระดับการดูแลผู้ป่วยด้วย AI

## แนวคิดนวัตกรรม

| นวัตกรรม | ทำอะไร | AI ที่ใช้ |
|---|---|---|
| **ครูปัญญา: AI สัมภาษณ์ภูมิปัญญา** | หมอเล่าตำรับยาด้วยเสียง → AI เรียบเรียงเป็นหน้าสมุดข่อยดิจิทัล → **AI ถามต่อ** เพื่อดึงความรู้ที่ไม่มีในตำรา (ฤดูเก็บยา วิธีเลือกวัตถุดิบ เคล็ดลับ) | ASR + LLM + TTS |
| **เล่าอาการผู้ป่วยด้วยเสียง** | พูดอาการ → สรุปอาการสำคัญ, ธาตุเจ้าเรือนที่กำเริบ, สมุนไพรแนะนำ, ข้อควรระวังกับยาแผนปัจจุบัน, สัญญาณอันตรายที่ต้องส่งต่อ รพ.สต. | ASR + LLM + TTS |
| **สแกนสมุดข่อย/ใบลาน** | ถ่ายภาพตำราเก่า → OCR → ถอดความภาษาปัจจุบัน → แยกตัวยา → เก็บเข้าคลัง | Typhoon OCR + LLM |
| **ต้นไม้ภูมิปัญญา** | วัดความคืบหน้าการบันทึกความรู้ (เรื่อง/นาที/ลูกศิษย์) เป็นแรงจูงใจส่งต่อให้คนรุ่นหลัง | — |
| **Voice‑first สำหรับผู้สูงอายุ** | ทุกหน้าสำคัญพูดได้ และฟังเป็นเสียงได้ ไม่ต้องพิมพ์ | ASR + TTS |

## AI Cloud ที่เชื่อมต่อ (`src/api/ai.ts`)

| บริการ | Endpoint | ใช้ทำ |
|---|---|---|
| LLM | `vllm-gemma` → `/v1/chat/completions` (model `gemma4` = Gemma 4 31B, ดูภาพได้) | วิเคราะห์, เรียบเรียง, แชท, สแกนสมุนไพรจากภาพ |
| ASR | `asr2` → `/v1/audio/transcriptions` (Qwen3‑ASR‑1.7B) | เสียง → ข้อความ (อัด WAV 16kHz mono, m4a ใช้ไม่ได้) |
| TTS | `vox-cpm` → `/v1/audio/speech` (voxcpm‑thai) | ข้อความ → เสียงพูดไทย |
| OCR | `pdf-ocr-mcp/api` → `/ocr_image/upload` (Typhoon OCR 1.5) | ภาพตำรา → ข้อความ |

ถ้าเชื่อมต่อ AI ไม่ได้ แอปจะแสดงผล **โหมดสาธิต** พร้อมป้ายกำกับ เพื่อให้ flow ไม่สะดุดระหว่างนำเสนอ

## Design System (`src/theme.ts`)

- **อ้างอิง UI:** Dribbble "Medical Mobile App" ([#14235513](https://dribbble.com/shots/14235513-Medical-Mobile-App), [#26947858](https://dribbble.com/shots/26947858-Medical-Mobile-App)), ดีไซน์สากลแบบ Soft Clinical
- **สี 60·30·10:** พื้นเทากลาง `#F4F5F7` + การ์ดขาว · ตัวอักษรกรมท่า `#1B2541` + การ์ดพาสเทล · น้ำเงิน `#3D7BF5` (ปุ่มหลัก/สถานะที่เลือก)
- **Liquid Glass (iOS 26):** แท็บบาร์ native (`expo-router/unstable-native-tabs`) ที่มีปุ่ม "ครูปัญญา" แยกเป็นวงกลมกระจก, ปุ่มกลม, ตัวสลับ และแถบปุ่มล่างใช้ `expo-glass-effect`
- **ตัวอักษร:** ฟอนต์ระบบและขนาดตาม Apple HIG (Body 17pt) โดยให้ Dynamic Type ของเครื่องปรับขนาดเอง
- **เอฟเฟกต์ AI แบบ Apple Intelligence (Skia):** ลูกแก้ว Siri, ขอบจอเรืองแสงไล่สีเวลา AI ฟัง/คิด/พูด, ขอบการ์ดไล่สีหมุน, waveform ไล่สี, shimmer ระหว่างคิด
- **Spacing:** ขอบจอ 16pt, grid 4pt · **Touch target ≥ 56pt**

## บันทึกผู้ป่วยตามแบบ ม.บ.5

ใช้รูปแบบ [แบบ ม.บ.5 ทะเบียนการรักษา](https://www.dtam.moph.go.th/wp-content/uploads/2023/11/4.5MHO4.pdf) ของกรมการแพทย์แผนไทยฯ
- **ข้อมูลทั่วไป:** ชื่อ-สกุล, เพศ, อายุ, ที่อยู่, โทรศัพท์, โรคประจำตัว, การแพ้ยา/อาหาร, น้ำหนัก, ส่วนสูง
- **ทะเบียนการรักษา:** ครั้งที่, ว/ด/ป, อาการเจ็บป่วย, ตรวจร่างกาย, วินิจฉัยโรค, การรักษา, ผลการรักษา, การติดตามผล, หมายเหตุ
- หมอเล่าด้วยเสียง → AI กรอกแบบฟอร์มให้ (ช่องที่ไม่ได้เล่าถึงจะเว้นว่างไว้ ไม่เดา) → ครูปัญญาบอกว่าขาดข้อมูลอะไร → ส่งออกเป็นข้อความผ่านปุ่มแชร์

## โครงสร้างหน้าจอ (Expo Router)

```
onboarding        แนะนำ → เลือกประเภทหมอ (6 ประเภท) → ขนาดตัวอักษร
(tabs)
 ├ index          หน้าหลัก: ครูปัญญา, เมนูด่วน, ต้นไม้ภูมิปัญญา, ฤดูกาล/ธาตุ, นัดหมาย, สมุนไพรประจำวัน
 ├ herbs          คลังสมุนไพร: ค้นหา + กรองตามรสยา
 ├ [ปุ่มไมค์]      → capture
 ├ patients       ผู้ป่วย: สรุปสถานะ + ตัวกรอง
 └ vault          คลังภูมิ: สมุดข่อยดิจิทัล
capture           เล่าด้วยเสียง (อาการผู้ป่วย / ถ่ายทอดภูมิปัญญา)
assistant         แชทครูปัญญา (พิมพ์/พูด, ฟังคำตอบ)
scan              สแกนตำรา (กล้อง/อัลบั้ม/ตัวอย่าง)
herb/[id] · patient/[id] · wisdom/[id] · settings
```
